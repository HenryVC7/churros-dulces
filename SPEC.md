# Churros Dulces - Especificación del proyecto
## objetivo
crear una página web moderna y adaptable a celulares para un negocio ficticio de churros.
la página permitirá mostrar los productos, agregarlos a un carrito y realizar pedidos.
## funcionalidades principales 
### 1. página de inicio
- presentar el negocio.
- mostrar una sección principal atractiva.
- mostrar un botón para ver los productos.
### 2. productos
- mostrar los productos disponibles.
- mostrar nombre, descripción y precio.
- permitir agregar productos al carrito.
### 3. carrito
- mostrar los productos seleccionados.
- mostrar cantidades.
- calcular el total.
- permitir eliminar productos.
### 4. realizar pedido 
- solicitar nombre del cliente.
- solicitar teléfono.
- solicitar dirección.
- mostrar resumen del pedido.
### 5. WhatsApp
- crear un mensaje con el pedido.
- permitir enviar el pedido mediante WhatsApp.
## diseño
- diseño moderno
- adaptable a computadoras, tablets y celulares
- interfaz sencilla.
- botones fáciles de identificar.
- enfoque en una buena experiencia de usuario.

## estado
Carrito y pedidos implementados: cantidades, eliminación, subtotales, total, formulario con validación y vista previa del pedido.
La integración mediante `wa.me` fue probada localmente, según confirmación del usuario. El cliente confirma el envío dentro de WhatsApp.
El número comercial está intencionalmente sin configurar. Antes de publicar la web debe configurarse un número comercial autorizado y verificarse el envío al destinatario correcto. El número personal de prueba fue retirado.

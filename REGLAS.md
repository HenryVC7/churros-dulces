# Churros Dulces - Reglas del proyecto

## Código

- Mantener el código sencillo y fácil de entender.
- Utilizar nombres claros para variables, funciones y archivos.
- Evitar código innecesariamente complicado.
- Comentar el código cuando sea necesario para explicar algo importante.

## Diseño

- Mantener una interfaz limpia y moderna.
- La página debe funcionar correctamente en celulares y computadoras.
- Priorizar una buena experiencia de usuario.

## Desarrollo

- Seguir el ROADMAP del proyecto.
- No agregar funcionalidades importantes sin definirlas primero.
- Probar las funcionalidades después de implementarlas.
- Evitar instalar herramientas que no sean necesarias.

## Inteligencia artificial

- La IA debe explicar los cambios importantes que realice.
- La IA no debe modificar archivos sin considerar la estructura existente del proyecto.
- Antes de realizar cambios grandes, revisar la documentación del proyecto.
- Mantener las decisiones importantes documentadas.

## Seguridad

- Nunca colocar contraseñas, API keys o secretos directamente en el código.
- No publicar información privada.
- Revisar cualquier integración externa antes de utilizarla.

# Churros Dulces - Instrucciones para agentes

## Contexto y aprendizaje

- El proyecto se llama Churros Dulces.
- El usuario está aprendiendo desarrollo web desde nivel principiante.
- Explica los cambios de forma sencilla y educativa.

## Antes de implementar

- Antes de implementar una tarea, revisa SPEC.md, ROADMAP.md, REGLAS.md y DECISIONES.md.
- Sigue las fases definidas en ROADMAP.md.
- No adelantes funcionalidades de fases posteriores sin autorización del usuario.
- Si una instrucción es ambigua y puede provocar cambios importantes, pregunta antes de realizarla.

## Tecnologías y cambios

- Usa HTML, CSS y JavaScript puro mientras el roadmap no indique lo contrario.
- No agregues frameworks, librerías ni dependencias sin justificarlo y pedir autorización al usuario antes de agregarlos.
- Haz cambios pequeños y fáciles de revisar.
- No cambies partes del proyecto que no estén relacionadas con la tarea solicitada.
- Mantén el diseño responsive, adaptable a celulares, tablets y computadoras.

## Seguridad y revisión

- Nunca coloques API keys, contraseñas, tokens o secretos directamente en el código.
- Después de modificar código, revisa posibles errores.
- Explica qué archivos modificaste y por qué.

## Git

- No hagas git commit ni git push automáticamente, salvo que el usuario lo solicite explícitamente.
